# Florants Residence

Premium Airbnb-style hospitality website for Florants Residence, built with Next.js, Tailwind CSS, Framer Motion, Swiper, Lucide React, and `next/image`.

## Run locally

```bash
npm install
npm run dev
```

## Image folders

Place property images in:

- `public/images/hero`
- `public/images/living-room`
- `public/images/kitchen`
- `public/images/dining`
- `public/images/bedroom-1`
- `public/images/bedroom-2`
- `public/images/bathroom-1`
- `public/images/bathroom-2`
- `public/images/exterior`
- `public/images/host`
- `public/images/logo`

The gallery and hero are discovered from these folders at render time. Local SVG starter images are included so the site remains complete before real photos are added.
